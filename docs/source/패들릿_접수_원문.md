# data10-08 · 박상선

## 접수 글
### 프레임 제작 생산성 개선

① 직무·소속 : (회사명 생략) 제작팀 / 프레임 제작

② 현안 : 일일 가용시간 내에 현재 인원으로 프레임 제작 목표 실적 대수 대비 달성률을 90% 이상으로 확보해야 함. 이를 위해 작업별 소요시간과 생산 지연 요인을 파악하고, 인원 증원 없이 작업 방법과 공정 운영을 개선하고자 함.

목표 1. 가용시간 대비 생산능력 분석 — 일일 실작업 가능시간과 공정별 소요시간을 확인하고, 목표 실적 대수에 필요한 대당 목표시간을 산출함. 실제 작업시간과 비교하여 생산량을 제한하는 병목공정을 파악함.

목표 2. 작업 개선을 통한 목표 실적 대수 대비 달성률 90% 이상 확보 — 자재 준비, 이동, 대기, 재작업 등 손실시간을 줄이고 작업 순서와 인원별 업무 배분을 개선함. 개선된 작업 방법을 표준화하여 현재 인원으로 품질과 안전을 유지하면서 달성률 90% 이상을 확보함.

③ 보유·수집 필요 데이터 : 현재 투입 인원, 일일 가용시간, 목표 실적 대수, 실제 생산 대수, 공정별 작업시간, 작업자별 업무, 자재·설비 대기시간, 재작업 발생 내역, 대당 투입공수 및 제작원가 내역 ※ 실제 보유 여부 확인 후 부족한 항목은 현장 측정으로 확보

④ 기대 산출물 : 가용시간 대비 목표 실적 대수 및 실제 생산 대수, 달성률 관리표 / 공정별 작업시간 분석표와 병목공정 개선안 / 작업 순서 및 인원 배분 개선안 / 개선 전·후 생산량과 손실시간 비교표 / 제작 단가 절감 효과 분석표(개선 전·후 대당 투입공수와 제작원가 비교, 대당 절감액·절감률) / 목표 실적 대수 달성을 위한 표준작업서. 핵심 성과지표: 현재 인원 유지 / 달성률 90% 이상 / 제작 단가 절감액 및 절감률

## 이미 요청한 확인 사항 (강사 → 수강생)

- 최근 1~2주 일일 실적(날짜·목표·실제·인원·가용시간)
- 프레임 제작 공정 순서와 공정별 표준시간
- 대기·재작업 사유 기록
- 대당 투입공수·제작원가 계산 방식
- 공정별 시간이 없으면 2~3일 현장 측정표 양식부터
