# data10-08 · 프레임 제작 생산성 개선

일일 실적으로 목표 대수 대비 달성률(90% 선)을 관리하고, 현장 측정으로 공정별 작업시간·손실을 재어 병목공정·인원 배분·개선 전후 단가 절감을 분석하며 표준작업서 초안을 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 박상선 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 (2026-10-20) · 최종 기획서 v2.0 · 로그인 · 현장 측정 → 일일 실적 자동 반영 · v2.1 측정 항목 편집 · 일시정지 · **v2.3 일일 실적 입력란 정리 (2026-11-10)** — https://data10-08.jobability.co.kr/ |
| 다음 개발 | 2단계 — 실제 실적·측정 자료로 계산 정의 보정(가용시간·투입공수·원가), 한 사람만 할 수 있는 작업·선후 관계를 반영한 인원 배분, 팀 공유 저장소, 기존 작업표준서 근거 확인 |

> 과제는 패들릿으로 접수했습니다. 첨부 자료는 아직 없고, 이 리포의 샘플은 모두 **가상 값**입니다(작업자A~I, 가짜 임률·원가). 회사명은 리포에 두지 않습니다.

## 로그인 · 사용 승인

- 처음 쓰는 분은 대문의 「회원가입」에서 **회사 메일이나 개인 메일 + 비밀번호**(8자 이상)와 이름 · 소속 · 연락처를 넣고 「가입하고 사용 신청」을 누릅니다. 카카오로 로그인해도 됩니다.
- **관리자가 승인하면** 바로 쓸 수 있습니다. 관리자는 오른쪽 위 「구성원 관리」에서 승인 · 사용 중지를 하고, 「관리자로 지정」한 사람도 팀원을 승인할 수 있습니다. 처음에는 강사 계정이 관리자이고, 요청자를 관리자로 올리면 요청자가 자기 팀을 승인합니다.
- 로그인 정보만 Supabase 표 `data1008_members` 에 남습니다. **업무 자료는 서버로 보내지 않고** 이 브라우저(localStorage)에 저장합니다 — JSON 백업을 받아 두세요.
- 내 PC(`localhost` · 파일로 열기)에서는 로그인을 건너뜁니다. 내 PC 에서 로그인 화면을 보려면 주소 끝에 `?auth=1` 을 붙입니다.

### 2026-11-10 요청 반영 (v2.3) — 일일 실적 입력란 정리

실적 수정 기능과 겹치는 「현장 실적 입력」 카드를 뺐습니다. 일일 실적은 이제 이렇게 들어옵니다.

| 길 | 쓰는 때 |
|---|---|
| 현장 측정 자동 반영 | 「다음 대」로 끝낸 마지막 공정 완료 수가 그날 실제 대수로 들어갑니다(손으로 고친 값과 다르면 「측정값 쓰기 / 입력값 유지」). |
| 엑셀 가져오기 | 여러 날을 한 번에 넣거나 기존 실적표를 옮길 때. |
| 날짜 더하기 → 고치기 | 측정이 없는 날 하루치. 표 위에서 날짜를 골라 「날짜 더하기」를 누르면 그 줄이 생기고 바로 고치기 화면이 열립니다(목표는 설정 기본값, 인원 · 가용시간은 비우면 기본값으로 계산). 저장하지 않고 닫으면 빈 줄은 지워집니다. |
| 표의 「고치기」 · 「지우기」 | 이미 있는 날의 값을 바꾸거나 지울 때. 고치기 화면은 누를 때만 열립니다. |

### 2026-11-10 추가 요청 반영 (v2.1) — 측정 항목 편집 · 일시정지

| 어디서 | 무엇을 |
|---|---|
| 공정 설정 · 측정 항목 | 스톱워치 · 측정표의 구분(작업 · 세팅 · 자재 준비 · 이동 · 대기 · 재작업 · 기타 · 휴식)을 **이름 바꾸기 · 더하기 · 순서(위/아래) · 숨기기**. 항목마다 **분류**(작업 시간 / 준비(세팅) / 손실 / 비작업(휴식 등))를 고릅니다. 기록은 항목으로 저장되어 이름을 바꿔도 지난 기록이 새 이름으로 따라가고, 계산은 분류로 합니다. 숨긴 항목은 스톱워치 · 측정표에서만 빠집니다. |
| 현장 측정 · 스톱워치 | **「일시정지 / 다시 시작」**. 일시정지 동안 지금 구간 시간은 멈추고, 멈춘 시간은 「일시정지」로 따로 남습니다. 「다시 시작」은 멈췄던 항목으로 이어 잽니다. 새로 고쳐도 일시정지 상태가 이어집니다. |
| 계산 | **사이클타임 = (작업 시간 항목의 합 [+ 세팅]) ÷ 측정 대 수 ÷ 인원.** 손실 · 휴식 등 · 일시정지는 빠집니다. 세팅을 넣을지는 측정 항목 카드의 확인란(기본 끔). |
| 대시보드 · 손실 분석 · 보고서 | **비작업 시간(세팅 · 휴식 · 일시정지)** 요약 카드 · 엑셀 시트, AI 프롬프트에도 사실로 들어갑니다. |
| 측정표 · 엑셀 | 빈 측정표 인쇄 · 빈 엑셀 작성 방법 · 내려받기가 지금 항목 이름을 따릅니다. 가져오기는 지금 이름 → 옛 이름(별칭) 순서로 읽습니다. |

### 2026-11-10 요청 반영 — 현장 측정 → 일일 실적 자동 반영

| 어디서 | 무엇을 |
|---|---|
| 공정 설정 | 공정마다 **하루 CAPA(대/일)** 를 넣습니다(비우면 4). |
| 현장 측정 · 스톱워치 | 한 대를 끝내면 **「다음 대」**, 그날 마지막 대는 **「완료하고 멈춤」**, 끝내지 않고 멈출 때는 「멈춤(미완료)」. 측정 엑셀은 선택 칸 「대 완료」(○)를 읽습니다(비우면 작업 구간이 있는 대를 완료로 셈). |
| 현장 측정 · 진행 현황 | **공정별 진행 현황**(공정 × 완료/CAPA · 사이클타임 · 판정)과 **날짜별 공정 진행** 표. 지연 = 완료 < CAPA 또는 사이클타임 > 택트타임. |
| 일일 실적 | **마지막 공정 완료 수**가 그날 실제 대수로 자동으로 들어갑니다(「측정 반영」). 손으로 넣은 값과 다르면 덮어쓰지 않고 「측정값과 손 입력이 다른 날」 카드에서 「측정값 쓰기 / 입력값 유지」를 고릅니다. |
| 대시보드 | 「오늘 공정 진행 · 지연 공정」 카드(오늘 측정이 없으면 최근 측정일). |

## 실행 방법

**온라인에서 바로 보기: https://data10-08.jobability.co.kr/**

처음 열면 「대시보드」입니다. **「가상 샘플로 시작」** 을 누르면 일일 실적 7주와 현장 측정 5일(개선 전 3일 · 개선 후 2일)이 들어갑니다.
샘플에는 일부러 **개선 전에는 본용접이 병목**(사이클타임 약 55분 > 택트타임 45분)이고 **「대기」 손실이 가장 크게**, 09/21 인원 배분을 바꾼 뒤에는 **달성률이 90%를 넘게** 만들어 두었습니다. 화면 위 기간 단추(「개선 전」「개선 후」)로 바꿔 보세요.

실제로 쓸 때는 현장 측정을 하면 일일 실적이 자동으로 채워지고, 여러 날은 엑셀로 가져오며, 측정이 없는 날은 「일일 실적」의 「날짜 더하기」로 줄을 만들어 고칩니다. 공정별 시간이 없으면 「현장 측정」에서 2~3일 잽니다(휴대폰 스톱워치 또는 빈 측정표 인쇄). 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).
